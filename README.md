## `01` &nbsp; About Me

I'm a Computer Science and Engineering student specializing in **Artificial Intelligence and Machine Learning**, focused on building intelligent software systems that solve real-world problems.

My work combines software engineering fundamentals with applied AI research, computer vision, reinforcement learning, natural language processing, and full-stack development. I enjoy taking ideas from research papers and experimental models to integrated applications with usable interfaces, practical workflows, and measurable outcomes.

I approach engineering with a **product-first mindset**: understand the problem, select the right architecture, build a reliable solution, evaluate its performance, and make it useful to the people who need it.

- **Software Engineering:** Data structures, algorithms, object-oriented programming, modular architecture, and API development.
- **AI/ML Engineering:** Computer vision, transformer architectures, reinforcement learning, NLP, RAG, and LLM integration.
- **Full-Stack Development:** Python, Flask, FastAPI, Next.js, Streamlit, and database integration.
- **Applied Research:** Model evaluation, experimentation, feature engineering, and research-driven prototyping.
- **Product Engineering:** End-to-end development, system integration, real-world problem solving, and iterative improvement.

**Currently open to:** AI/ML internships, software engineering opportunities, applied research collaborations, and open-source projects.

<br/>

An AI-powered agriculture platform combining computer vision, reinforcement learning, and retrieval-augmented generation to provide contextual crop disease detection and agricultural guidance.

| Dimension | Details |
|:---|:---|

| **Security** | Security controls and formal security evaluation are not documented here |
| **Impact** | Selected for Smart India Hackathon 2026; designed to support contextual agricultural decision-making |
| **Repository** | [View on GitHub](https://github.com/NabhKrishi/NabhKrishi_frontend) |

**Engineering highlights**

- Implemented a Swin Transformer-based classifier for wheat disease classification.
- Integrated PPO-based decision support into the agricultural guidance workflow.
- Developed a RAG chatbot using ChromaDB, BGE embeddings, and NVIDIA Nemotron.
- Integrated farm mapping and designed the platform to incorporate weather, satellite, and agricultural data.

</details>

<details>

| Dimension | Details |
|:---|:---|

| **Scale** | 2,100+ clinical Alzheimer's records; four risk tiers |

| **Security** | SQLite-based data storage; formal security audit not documented |
| **Impact** | Combines predictive modeling, cognitive screening, and automated reporting in one prototype |
| **Repository** | [View repositories](https://github.com/TanishkaVashishth?tab=repositories) |

**Engineering highlights**

- Built a Random Forest Regressor-based neurological risk prediction workflow.
- Integrated interactive reaction-time and memory-recall assessments.
- Added lifestyle analytics and SQLite-based longitudinal tracking.
- Implemented automated PDF report generation using ReportLab.

*This is a student prototype and is not a substitute for professional medical evaluation.*

</details>

<details>
<summary><strong>03. Attention Drift & Fatigue Detection</strong> &nbsp; <code>Computer Vision</code> <code>Real-Time ML</code></summary>

<br/>

A real-time monitoring system combining facial features and system-level telemetry to identify indicators of drowsiness and distraction.

| Dimension | Details |
|:---|:---|
| **Stack** | Python, MediaPipe, OpenCV, Streamlit, Machine Learning |
| **Scale** | Real-time facial feature extraction and distraction-monitoring workflow |
| **Performance** | Model accuracy and latency benchmarks not documented here |
| **Security** | Uses camera input and system telemetry; formal privacy/security audit not documented |
| **Impact** | Live risk scoring, alerts, and automated PDF reporting |
| **Repository** | [View repositories](https://github.com/TanishkaVashishth?tab=repositories) |

**Engineering highlights**

- Extracted facial landmarks and derived Eye Aspect Ratio (EAR), Mouth Aspect Ratio (MAR), and head-pose features.
- Trained a machine-learning classifier using the NTHU-DDD driver drowsiness dataset.
- Integrated computer vision with system-level telemetry to monitor potential attention drift.
- Built a Streamlit dashboard with live alerts, risk scoring, and PDF report generation.

</details>

<details>
<summary><strong>04. TerraViT — Vision Transformer for Earth's Climate Intelligence</strong> &nbsp; <code>Satellite AI</code> <code>Computer Vision</code></summary>

<br/>

An Earth Observation platform combining a satellite-pretrained vision transformer with climate data to analyze environmental changes and generate geospatial risk insights.

| Dimension | Details |
|:---|:---|
| **Stack** | PyTorch, SatViT, FastAPI, Next.js 14, ERA5 climate data |
| **Scale** | 12-layer encoder with 768-dimensional representations |
| **Performance** | Third place at Global AI Summit 2025; quantitative detection benchmarks not documented here |
| **Security** | Formal security audit not documented |
| **Impact** | Change heatmaps, vegetation-stress and flood masks, climate-risk trends, and early-warning alerts |
| **Repository** | [View repositories](https://github.com/TanishkaVashishth?tab=repositories) |

**Engineering highlights**

- Integrated a satellite-pretrained Masked Autoencoder Vision Transformer.
- Implemented before-and-after change detection using per-patch latent differences.
- Added an RGB-to-multispectral channel adapter for the processing workflow.
- Developed a FastAPI backend and Next.js dashboard with geospatial risk profiling.
- Integrated 10-year ERA5 climate-risk trends and an early-warning engine using Server-Sent Events (SSE) and webhooks.

</details>
